# Notion interchange

This is a temporary staging area for material moving between the repository and Notion.

Recommended convention:

- `inbox/YYYY-MM-DD-topic/` for exports or material pulled from Notion;
- `outbox/YYYY-MM-DD-topic/` for material prepared for import or publishing;
- a short README or manifest in each transfer folder stating its source, destination, date, and whether generated files may be edited.

This directory is not the canonical long-term home for character or campaign content. Move cleaned material into the appropriate domain directory, and avoid mixing generated exports with hand-edited source files.
