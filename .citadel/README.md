# Citadel workspace

This directory is for repository-level operational material used by humans and AI agents.

Appropriate content includes:

- implementation or migration plans;
- architecture and organization decisions;
- automation notes;
- agent handoffs and task context;
- repository maintenance documentation.

Character concepts, campaign lore, and ordinary game material belong in the visible domain directories instead. Create `plans/`, `decisions/`, or other subdirectories here only when they are needed.
